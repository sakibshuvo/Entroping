# Launch Demo Assets

Generated from real checkout fixture output, not from mocked product copy.

These assets are intentionally text-first so they stay reviewable in Git and
usable in Obsidian. Record GIFs or PNG screenshots from the same source commands
when publishing externally, but do not commit bulky generated media unless it is
curated and size-checked.

## Asset Index

- [Terminal demo screenshot set](terminal-demo-screenshot-set.md) - the
  two-minute command sequence and current terminal frames from
  `scripts/live_demo_smoke.sh`.
- [HTML report screenshot](html-report-screenshot.svg) - a small SVG preview
  of the current `reports/run-latest.html` output.
- [Dependency map example](dependency-map-example.md) - Markdown and Mermaid
  output generated by the dependency-map renderer from redacted traffic state.

## Rebuild Source

From the repository root:

```bash
artifact_dir="$(mktemp -d /Users/sakibshuvo/projects/entroping-demo-artifacts.XXXXXX)"
workdir="$(mktemp -d /Users/sakibshuvo/projects/entroping-demo-work.XXXXXX)"
ENTROPING_LIVE_DEMO_ARTIFACT_DIR="$artifact_dir" \
  ENTROPING_LIVE_DEMO_WORKDIR="$workdir" \
  scripts/live_demo_smoke.sh
```

The smoke script copies only generated report artifacts to the artifact
directory. Keep those generated files out of Git unless a specific public asset
has been reviewed.
